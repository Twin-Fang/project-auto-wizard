## Try it

Run it in the root of your repository (Node.js 20.12 or later):

```bash
npx project-auto-wizard
```

It detects the project type, asks a few questions and writes the workflow files. For CI or scripts:

```bash
npx project-auto-wizard --mode full --force --type spring,react
```

## What you get

<CardGrid>
  <Card title="Release PR automation" icon="rocket">
    Open a `develop → main` PR and the next version is derived from commit types, release notes are written, CHANGELOG is updated and the PR automerges.
  </Card>
  <Card title="Tags and GitHub Releases" icon="approve-check">
    After the merge, a `vX.Y.Z` tag and a GitHub Release are published and the README version line is updated.
  </Card>
  <Card title="CI/CD per stack" icon="seti:pipeline">
    Spring, Flutter, React, Next.js, Python and Go get CI and deploy workflows. Other types get release automation only.
  </Card>
  <Card title="No API keys" icon="padlock">
    Release notes are rule-based by default. GitHub Copilot or an OpenAI-compatible API is optional, and failures fall back to the rules.
  </Card>
  <Card title="Files you own" icon="document">
    Workflows and standard-library Python scripts are copied into `.github/`. Read them, edit them; re-running keeps your changes.
  </Card>
  <Card title="Read-only checks" icon="magnifier">
    `--mode status` shows drift against the installed templates, and `--mode doctor` checks the repository settings the workflows need.
  </Card>
</CardGrid>
