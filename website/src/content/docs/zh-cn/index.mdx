## 试一试

在仓库根目录运行（需要 Node.js 20.12 或更高版本）：

```bash
npx project-auto-wizard
```

它会检测项目类型，询问几个问题，然后写入工作流文件。在 CI 或脚本中以非交互方式运行：

```bash
npx project-auto-wizard --mode full --force --type spring,react
```

## 安装内容

<CardGrid>
  <Card title="发布 PR 自动化" icon="rocket">
    打开 `develop → main` 的 PR 后，根据提交类型确定下一个版本，生成发布说明，更新 CHANGELOG，并自动合并。
  </Card>
  <Card title="标签与 GitHub Release" icon="approve-check">
    合并后发布 `vX.Y.Z` 标签和 GitHub Release，并更新 README 中的版本行。
  </Card>
  <Card title="按技术栈的 CI/CD" icon="seti:pipeline">
    Spring、Flutter、React、Next.js、Python、Go 会安装 CI 和部署工作流。其他类型只安装发布自动化。
  </Card>
  <Card title="无需 API Key" icon="padlock">
    发布说明默认基于规则生成。GitHub Copilot 或 OpenAI 兼容 API 是可选的，失败时回退到规则。
  </Card>
  <Card title="文件归你所有" icon="document">
    工作流和只用标准库的 Python 脚本会复制到 `.github/`。可以阅读、修改；重新运行会保留你的修改。
  </Card>
  <Card title="只读检查" icon="magnifier">
    `--mode status` 显示与安装模板的差异，`--mode doctor` 检查工作流依赖的仓库设置。
  </Card>
</CardGrid>
