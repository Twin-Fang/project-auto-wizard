⚙️[기능추가][대회제출] status/doctor/dry-run/AI PR 요약봇/자동 semver 승격 구현

📝 현재 문제점
---

- 오픈소스 개발자대회(osscontest.kr) 제출을 위한 스코프 결정(`docs/superpowers/specs/2026-07-25-osscontest-scope-design.md`)은 브레인스토밍 세션을 통해 확정됐지만, 실제 구현은 아직 하나도 진행되지 않았다.
- 커뮤니티 거버넌스 문서(CONTRIBUTING/CODE_OF_CONDUCT/SECURITY/ROADMAP/이슈·PR템플릿), 핵심 모듈(`breaking-check.js`/`wizard-labels.js`/`wizard-env.js`) 테스트 커버리지 공백, `status`/`doctor`/`--dry-run` 명령, CodeRabbit 비의존 자체 AI PR 요약봇, 커밋 타입 기반 자동 semver 승격 기능이 전부 미구현 상태다.

🛠️ 해결 방안 / 제안 기능
---

`docs/superpowers/plans/2026-07-28-osscontest-implementation.md`에 정리된 26개 태스크(Phase 0~7)를 순서대로 구현한다.

- **Phase 0** — 커뮤니티 거버넌스 문서(CONTRIBUTING/CODE_OF_CONDUCT/SECURITY/ROADMAP/이슈·PR템플릿) + README 문서화 갭
- **Phase 1** — `breaking-check.js`/`wizard-labels.js`/`wizard-env.js` 테스트 커버리지 + 의존성 라이선스 리포트
- **Phase 2** — `planWorkflows()` 공유 인프라 + `status`(설치 상태·드리프트 확인) 명령
- **Phase 3** — `doctor`(규칙 기반 환경 진단) 명령
- **Phase 4** — `revert.js`의 plan/execute 분리 + `--dry-run` 미리보기 모드(full/version/workflows/revert 전체)
- **Phase 5** — AI 요약 프롬프트에 `git diff --stat` 컨텍스트 확장
- **Phase 6** — 자체 AI PR 요약봇 신설(CodeRabbit과 상호 배타적, 기존 `coderabbit` 옵션 재사용)
- **Phase 7** — 자동 semver 승격(`feat:`→minor, `!`마커→major, 규칙 우선 + patch→minor 상한의 AI 보조판단)

🧭 구현 가이드
---

- 태스크마다 수정할 파일 경로·함수 시그니처·테스트까지 구체적으로 명시되어 있어, 이 이슈 본문에 재나열하지 않고 아래 문서를 단일 진실로 참조한다.
- 스펙: `docs/superpowers/specs/2026-07-25-osscontest-scope-design.md`
- 구현 계획: `docs/superpowers/plans/2026-07-28-osscontest-implementation.md` (26개 태스크, Fable 모델 최종 검토로 HIGH 4건·MEDIUM 5건 수정 반영 완료)
- 실행은 `superpowers:subagent-driven-development` 또는 `superpowers:executing-plans`로 태스크 단위 진행 예정.
