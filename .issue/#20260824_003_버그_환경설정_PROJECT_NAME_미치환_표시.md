❗[버그][마법사] 환경설정 질문·요약에서 __PROJECT_NAME__ 토큰이 실제 값으로 치환되지 않고 그대로 표시됨

무슨 일이 있었나요?
---

`npx project-auto-wizard`로 go 프로젝트에 전체 설치를 진행하는 중, `VOLUME_CONTAINER_PATH`(컨테이너 내부 마운트 경로) 등 일부 항목에서 Enter로 기본값을 그대로 유지하면, 입력 확인 메시지와 설치 완료 화면의 "적용된 환경설정" 요약에 아래처럼 템플릿 플레이스홀더가 미치환 상태로 그대로 노출됩니다.

```
◆  ↳ 값 입력 (Enter=기본값 «/mnt/__PROJECT_NAME__» 유지):
         → 컨테이너 내부 마운트 경로 = /mnt/__PROJECT_NAME__

  ⚙️  적용된 환경설정:
     • 컨테이너 내부 마운트 경로: /mnt/__PROJECT_NAME__ (기본값)
```

실제로 생성된 `.github/workflows/PROJECT-GO-SIMPLE-CICD.yaml` 파일을 직접 열어보면 `VOLUME_CONTAINER_PATH: "/mnt/claude-window-keeper"`처럼 리포지토리 이름으로 정상 치환되어 있어, **워크플로우 파일 자체는 정상**입니다. 문제는 마법사 CLI가 보여주는 질문 카드 · 입력 확인 echo · 완료 요약 · 설치 기록 로그(`.github/.wizard/logs/*.md`) 쪽에서만 미치환 값을 표시한다는 점입니다.

기대했던 동작
---

- 질문 카드의 "기본값" 표시, 입력 확인 echo(`→ 라벨 = 값`), 완료 화면의 "⚙️ 적용된 환경설정" 요약, 설치 기록 로그 모두 실제로 워크플로우 파일에 쓰이는 값(예: `/mnt/claude-window-keeper`)과 동일하게 표시되어야 합니다.
- `summary.js`의 주석에도 이 요약이 "마지막으로 눈으로 검산할 기회"라고 명시되어 있는 만큼, 미치환 플레이스홀더가 보이면 검증 목적을 달성하지 못합니다.

🔍 원인 분석 및 수정 방향
---

- 원인: `src/ui/env-plan.js`의 `collectAsks()`(약 78~82번 줄)가 `@wizard ask` 마커의 기본값(`p.arg`)을 계산할 때 `@`로 시작하는 resolver 토큰(`@repo` 등)만 해석하고, 리터럴 문자열 안에 박힌 `__PROJECT_NAME__` / `__APP_ARTIFACT_NAME__`은 그대로 남겨둡니다. 이 값이 `printFieldCard()`(카드 표시), `promptEach()`(입력 확인 echo), `buildAnswers()`(→ `src/ui/summary.js`의 "적용된 환경설정" 및 설치 로그)까지 그대로 흘러갑니다.
- 반면 실제 파일 치환은 `src/core/wizard-env.js`의 `substituteEnv()`가 파일 전체 텍스트에 대해 `__PROJECT_NAME__` / `__APP_ARTIFACT_NAME__`을 전역 치환(약 91~93번 줄)하기 때문에, 최종 설치 파일에는 정상적으로 리포지토리 이름이 들어갑니다. 즉 CLI 표시 로직과 실제 파일 치환 로직이 서로 다른 경로로 동작하면서 표시만 어긋난 상태입니다.
- 영향받는 워크플로우 템플릿(‎`@wizard ask` 기본값에 `__PROJECT_NAME__`이 리터럴로 포함된 경우):
  - `payload/workflows/go/PROJECT-GO-SIMPLE-CICD.yaml` (`VOLUME_HOST_PATH`, `VOLUME_CONTAINER_PATH`)
  - `payload/workflows/go/PROJECT-GO-PR-PREVIEW.yaml` (`PROJECT_TARGET_DIR`, `PROJECT_MNT_DIR`)
  - `payload/workflows/python/PROJECT-PYTHON-SIMPLE-CICD.yaml` (`VOLUME_HOST_PATH`, `VOLUME_CONTAINER_PATH`)
  - `payload/workflows/python/PROJECT-PYTHON-PR-PREVIEW.yaml` (`PROJECT_TARGET_DIR`, `PROJECT_MNT_DIR`)
  - `payload/workflows/spring/server-deploy/PROJECT-SPRING-SIMPLE-CICD.yaml` (`VOLUME_HOST_PATH`, `VOLUME_CONTAINER_PATH`)
  - `payload/workflows/spring/server-deploy/PROJECT-SPRING-NONSTOP-NGINX-CICD.yaml` (`NGINX_RP_CONF`, `VOLUME_HOST_PATH`)
  - `payload/workflows/spring/server-deploy/PROJECT-SPRING-NONSTOP-TRAEFIK-CICD.yaml` (`VOLUME_HOST_PATH`, `VOLUME_CONTAINER_PATH`)
- 수정 방향(추정): `promptEnvPlan()`은 이미 `repoName` 인자를 갖고 있으므로(`src/ui/env-plan.js` 약 179번 줄), 이를 `collectAsks()` 호출부까지 전달해 `typeDefault` 계산 시(또는 표시 직전) `__PROJECT_NAME__` / `__APP_ARTIFACT_NAME__` 리터럴도 `repoName`으로 치환하도록 보완이 필요해 보입니다.
