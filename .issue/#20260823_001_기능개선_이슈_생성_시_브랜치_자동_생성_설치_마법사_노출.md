🚀[기능개선][이슈헬퍼] 이슈 생성 시 브랜치 자동 생성 여부를 설치 마법사 질문으로 노출

### 어떤 문제를 해결하고 싶으신가요?

`Chuseok22/github-issue-helper`는 GitHub 이슈를 만들면 곧바로 main 기준으로 브랜치를 자동 생성해준다. project-auto-wizard도 이 기능을 갖고 있는지 코드로 확인해보니, 로직 자체는 이미 이식되어 있었다.

`.github/scripts/issue_helper.py`의 `create_branch_if_needed()`가 github-issue-helper의 브랜치 생성 로직(base 브랜치 ref의 SHA 조회 → `POST /git/refs`로 브랜치 생성, 이미 있으면 422를 받아 스킵)을 그대로 갖고 있다. `.github/workflows/PROJECT-COMMON-ISSUE-HELPER.yaml`의 워크플로우 주석을 보면 외부 액션 의존을 걷어내며 이 레포 안으로 이식한 것으로 보인다.

문제는 이 기능이 `ISSUE_HELPER_CREATE_BRANCH: "false"`로 **기본 꺼짐 + 설치 마법사 질문으로 노출되지 않는다**는 점이다.

- `payload/workflows/common/PROJECT-COMMON-ISSUE-HELPER.yaml`에도 동일한 하드코딩된 `"false"`가 들어 있어서, project-auto-wizard로 새 프로젝트를 설치하는 모든 사용자가 이 값을 그대로 받는다.
- 켜려면 설치된 레포에서 워크플로우 YAML 파일을 직접 열어 `"false"`를 `"true"`로 수동 수정해야 한다. 설치 마법사가 이 선택지를 안내하지 않으므로, 기능이 있다는 사실 자체를 모르고 지나가기 쉽다.
- 대화형 설치 마법사가 사용하는 `collectAsks()`(`src/ui/env-plan.js`)는 `payload/workflows/{타입}/` 아래 파일들의 `# @wizard ask:...` 주석 마커를 스캔해 질문을 만드는데, `payload/workflows/common/`은 이 스캔 대상에서 빠져 있다(`secret-backup`만 `includeSecretBackup` 옵션으로 예외적으로 스캔됨). 즉 지금 구조에서는 `ISSUE_HELPER_CREATE_BRANCH` 줄에 `@wizard ask` 마커를 붙여도 설치 질문으로 나타나지 않는다.

### 제안하는 해결 방법

기능 자체를 새로 만들 필요는 없고, "존재하지만 안 보이는" 상태를 "설치 시점에 선택 가능"한 상태로 바꾸는 것을 제안한다.

1. `src/ui/env-plan.js`의 `collectAsks()`가 `payload/workflows/common/`(secret-backup 제외)도 일반적으로 스캔하도록 확장한다. 지금 `secret-backup`을 `includeSecretBackup` 옵션으로 opt-in 스캔하는 것과 비슷한 방식으로, common 전체를 스캔 대상에 포함시키면 될 것으로 보인다.
2. `payload/workflows/common/PROJECT-COMMON-ISSUE-HELPER.yaml`의 `ISSUE_HELPER_CREATE_BRANCH: "false"` 줄에 `# @wizard ask:...` 마커를 추가해, 대화형 설치 시 "이슈 생성 시 main 기준으로 브랜치를 자동 생성할까요?" 같은 질문으로 노출한다. 기본값은 기존과 동일하게 "아니오(false)"로 유지해, 원치 않는 사용자에게 브랜치가 쌓이는 문제(#68에서 opt-in으로 전환된 이유)를 반복하지 않는다.
3. `payload/config/wizard-prompts.yml`에 해당 질문의 `label`/`help`/`example`을 추가한다.
4. `.github/workflows/PROJECT-COMMON-ISSUE-HELPER.yaml`(이 레포 자체가 쓰는 워크플로우)에도 동일한 마커를 반영할지 여부는 별도 판단이 필요하다 — 이 레포는 `payload/`를 셀프 배포하는 구조가 아니므로, 이 레포 자신의 이슈 헬퍼 설정은 이번 변경과 무관하게 유지될 수도 있다.

### 고려한 다른 방법(선택)

- 마법사 질문 없이 `ISSUE_HELPER_CREATE_BRANCH` 기본값 자체를 `"true"`로 바꾸는 방법도 검토했으나, `project-auto-wizard#68`에서 "이슈를 열 때마다 브랜치가 자동 생성되는 걸 막기 위해 의도적으로 opt-in 전환"했다는 배경이 있어 기본값 변경은 그 판단을 뒤집는 것이라 이번 제안에서는 제외했다.
- README나 설치 후 안내 메시지에만 "이 플래그를 켤 수 있다"고 문서화하는 더 가벼운 방법도 가능하지만, 다른 설정값들이 전부 설치 마법사 질문으로 노출되는 것과 일관성이 떨어져 후순위로 판단했다.
